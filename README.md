# ComfyUI (trimmed for GitHub)

This repository root contains the ComfyUI project with custom nodes for Higgs-Audio/Vibe/Voice Cloning workflows.

Note: Large model checkpoints and related binary assets are intentionally NOT included in this Git repo to keep the repository lightweight and within Git hosting limits.

What is included
- ComfyUI source code and custom nodes (all Python files under `custom_nodes/`)
- Configuration, workflows, and small helper scripts
- This README and `.gitignore`

What is NOT included (you must download these separately and place them under the indicated paths)

1) Model checkpoints / weights
- Path: `models/checkpoints/`
- Examples: large `.pt`, `.pth`, or `*.safetensors` checkpoint files for LLMs, audio models, or diffusion models.
- How to obtain: download from the model provider (e.g. Hugging Face) or your model source.
- Where to place: copy the checkpoint file(s) into `models/checkpoints/`.

2) Diffusers or UNet models
- Path: `models/diffusers/` and `models/diffusion_models/`, `models/unet/`
- Examples: Stable Diffusion weights or other diffusion-based models required by some nodes.
- How to obtain: follow the model's download instructions (Hugging Face or other provider).

3) VAE and Upscale models
- Path: `models/vae/`, `models/vae_approx/`, `models/upscale_models/`

4) Embeddings, CLIP, and other large encoder models
- Path: `models/embeddings/`, `models/clip/`, `models/clip_vision/`

5) Animatediff / Motion LoRA resources
- Path: `models/animatediff_models/`, `models/animatediff_motion_lora/`

6) Additional large assets
- Path: `output/`, `video/`, `temp/` — these are generated by ComfyUI at runtime and are ignored by git.

Recommended ways to download models

Option A — Hugging Face (recommended for many models)
1. Install the HF CLI and login:

```bash
pip install huggingface-hub
huggingface-cli login
```

2. Use `repo` or `snapshot_download` to get specific files and place them in the appropriate folder. Example (python):

```python
from huggingface_hub import snapshot_download
snapshot_download(repo_id="bosonai/higgs-audio-v2-generation-3B-base", local_dir="models/checkpoints/higgs-audio-v2")
```

Option B — direct download
- Download the checkpoint `.safetensors` or `.pt` file from the provider web UI and copy it into `models/checkpoints/`.

Option C — use `git lfs` if the model repo supports it

```bash
brew install git-lfs
git lfs install
# follow the model's instructions (often 'git clone' will use LFS automatically)
```

How to place files (example)

1. Create the folder if it doesn't exist:

```bash
mkdir -p models/checkpoints
```

2. Move the downloaded file into it:

```bash
mv ~/Downloads/higgs-audio.safetensors models/checkpoints/
```

3. Ensure permissions allow read access by the virtualenv/python process.

Quick setup notes

1. Create a Python virtual environment and install dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. If you use model families that require `transformers`, `accelerate`, `bitsandbytes`, or `torch`, follow the provider instructions for installing the right versions (M1/M2/Mac-specific builds if you use Mac hardware acceleration).

3. Restart ComfyUI after placing model files so the custom nodes detect them.
